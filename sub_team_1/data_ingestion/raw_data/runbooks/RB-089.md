# RB-089: Auth-Service Timeout Recovery
**Service:** auth-service
**Risk Tier:** High (Tier-2)

## Symptoms
- API Gateway throws HTTP 503 errors.
- `gateway-proxy` logs show upstream timeouts.

## Remediation Steps
If the authentication cache is locked or the recent deployment introduced a bottleneck, execute a rollback of the deployment to the previous stable tag.
Command: `kubectl rollout undo deployment/auth-service`
